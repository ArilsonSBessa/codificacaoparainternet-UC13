# Padaria Pão Quente — a primeira página

Primeira página da padaria do bairro, com a estrutura mínima completa de um documento HTML.

## Conteúdo

- `<title>`: Padaria Pão Quente — Pão francês saindo toda hora
- `<h1>`: Padaria Pão Quente
- Um `<p>` com o horário de funcionamento e outro com o endereço.

## Como abrir

1. Abra a pasta `padaria` no VS Code.
2. Clique em **Go Live**, na barra inferior.
3. A página abre em `http://127.0.0.1:5500/`.

## Confira

- [x] A aba mostra o título completo.
- [x] O endereço no navegador começa com `http://127.0.0.1:5500`.
- [x] Ao mudar o horário e salvar (Ctrl+S), a página se atualiza sozinha.

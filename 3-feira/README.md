# Feira de Ciências 2026 — duas páginas

| Arquivo | Título da aba | Conteúdo |
|---|---|---|
| `index.html` | Feira de Ciências 2026 | `<h1>` com o nome da feira e um parágrafo com a data e o local |
| `programacao.html` | Programação — Feira de Ciências 2026 | `<h1>` "Programação" e três parágrafos: manhã, tarde e noite |

## Como abrir no Live Server

1. Abra a pasta `feira` no VS Code.
2. Clique com o botão direito no `index.html` e escolha **Open with Live Server**.
3. A primeira página abre em `http://127.0.0.1:5500/`.
4. A segunda abre em `http://127.0.0.1:5500/programacao.html`.

## Confira

- [x] Cada aba mostra um título diferente.
- [x] Abrir só `http://127.0.0.1:5500/` mostra o `index.html`.

## Por que o servidor escolheu esse arquivo?

Quando o endereço termina em `/` e não diz o nome de nenhum arquivo, o servidor entrega o arquivo padrão da pasta. Por convenção, esse arquivo padrão se chama `index.html`.

# Floricultura Jardim Secreto — página de datas especiais

Página que apresenta a floricultura e lista as datas que mais vendem: Dia das Mães, Dia dos Namorados e Dia de Finados. Cada data fica num parágrafo, com uma frase sobre o que a loja oferece.

## Confira

- [x] O `<html>` tem `lang="pt-BR"`, que declara o idioma da página como português do Brasil.
- [x] O tradutor do navegador não oferece "traduzir do português", porque a página já diz que está em português.
- [x] Todo o texto visível está dentro do `<body>`. O único texto no `<head>` é o `<title>`, que aparece na aba.
